รายการรางวัลในระบบ

คำแนะนำการนำไปใช้งานฟรี 100% (Hosting Guide)

นำเว็บนี้ไปเผยแพร่ออนไลนและแชร์ให้เพื่อนเล่นได้ฟรี ไม่มีค่าใช้จ่าย

วิธีที่ 1: GitHub Pages (แนะนำที่สุด - ง่ายและฟรีถาวร)

  1. บันทึกไฟล์นี้เป็นชื่อ index.html
  2. สร้าง Repository ใหม่บน GitHub.com (ตั้งค่าเป็น Public)
  3. อัปโหลดไฟล์ index.html ขึ้น Repository
  4. ไปที่ Settings > Pages เลือก Branch เป็น main / master แล้วกด Save
  5. คุณจะได้ลิงก์เว็บไซต์ฟรีทันที (เช่น https://yourusername.github.io/wheel)

วิธีที่ 2: Vercel หรือ Netlify (ลากวางไฟล์เสร็จใน 30 วินาที)

  • สมัครสมาชิกฟรีที่ Netlify.com หรือ Vercel.com
  • ลากโฟลเดอร์ที่มีไฟล์ index.html วางในหน้า Deploy
  • รับ URL เว็บไซต์ฟรีพร้อม SSL (HTTPS) ใช้งานได้ทันที

การเชื่อมต่อฐานข้อมูลแชร์สต็อกเรียลไทม์ (Firebase)

แอพนี้ถูกออกแบบให้ทำงานผ่าน **Firebase Firestore Cloud Storage** ในตัวเรียบร้อยแล้ว ทุกเครื่องที่เปิดลิงก์พร้อมกันจะดึงข้อมูลรางวัลและจำนวนคงเหลือจากชุดเดียวกัน และอัปเดตสต็อกเรียลไทม์โดยอัตโนมัติเมื่อมีคนหมุนได้รางวัล!
